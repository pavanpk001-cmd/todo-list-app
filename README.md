# TaskR - Todo List Web Application

A modern, feature-rich todo list application built with React.

## Features

- ✅ Add tasks with text, due dates, and priority levels (Low, Medium, High)
- ✅ Mark tasks as completed/incomplete
- ✅ Edit tasks inline by double-clicking
- ✅ Delete individual tasks
- ✅ Filter tasks by status (All, Active, Completed)
- ✅ Filter tasks by priority
- ✅ Clear all completed tasks
- ✅ Persistent storage using localStorage
- ✅ Responsive design with dark theme
- ✅ Overdue task warnings

## How to Use

1. **Open the Application**: Open `index.html` in your web browser
2. **Add a Task**:
   - Type your task in the input field
   - Optionally set a due date
   - Choose a priority level
   - Click "Add" or press Enter
3. **Manage Tasks**:
   - Click the checkbox to mark tasks as complete
   - Double-click task text to edit inline
   - Use the ✎ button to edit or ✕ button to delete
4. **Filter Tasks**:
   - Use status filters: All, Active, Completed
   - Use priority filters: All Priority, Low, Medium, High
5. **Clear Completed**: Use the "Clear X completed" button to remove all completed tasks

## Technical Details

- Built with React 18
- Uses inline JSX transpilation with Babel
- Styled with CSS-in-JS
- Fonts: Syne and DM Mono from Google Fonts
- No build process required - runs directly in the browser

## Browser Support

Works in all modern browsers that support ES6 modules and React.
